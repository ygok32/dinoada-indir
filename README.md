# DinoAda kurulum dosyaları

Bu depo yalnızca DinoAda'nın indirilebilir kurulum dosyalarını barındırır; kaynak kod burada değildir.

Kurulum yönergeleri ve indirme bağlantıları, **www.dinoada.com** adresinde öğretmen hesabınızla giriş yaptıktan sonra **İndir** sekmesindedir.

| Dosya | Ne için |
|---|---|
| `DinoAda-Ogretmen.apk` | Öğretmen telefonu (Android) |
| `DinoAda-Tahta-Windows.zip` | Akıllı tahta (Windows) |
| `DinoAda-Tahta-Linux.tar.gz` | Akıllı tahta (Linux / Pardus) |

En son sürüm: [Releases](https://github.com/ygok32/dinoada-indir/releases/latest)
